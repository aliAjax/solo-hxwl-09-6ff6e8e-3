## 人员通行与应急清点台（门禁值班员）

顶部页签可在「巡检看板」与「通行与应急清点台」之间切换，原有看板与示例数据保持不变。通行台能力：

- **层级容量**：区域按 L0 更衣缓冲区 → L1 走廊 → L2 光刻准备间 → L3 核心工艺区 逐级维护，容量可在看板上 ±/不限调整，不能调到低于当前在区人数。
- **准入三关**：进入须同时满足 培训、健康核查、更衣资格；资质可在人员花名中维护。
- **逐级进出 / 刷卡去重 / 单人单区**：只能在相邻层级移动；重复刷卡不重复计数；同一人同时只在一个区域。
- **原子跨区**：来源区退出与目标区进入一起成功或一起失败（容量不足等任一条件不满足则原位不变）；访客与陪同人按 2 人成组、原子移动。
- **访客陪同**：访客仅在陪同人在场时进入；陪同人离开前必须「一起移动 / 先送访客离场 / 当面陪同交接」之一。
- **紧急封锁与清点**：封锁后禁止进入、只允许向外侧离场；清点按区域列出滞留人员、最近位置与停留时长。
- **持久化**：状态、容量与完整操作流水（成功/被拒均记录）写入 localStorage，刷新页面后仍在；可一键重置为示例数据。
